# Riverside Solar Financial Cash Flow Analyzer (prototype v1)

Static, dependency-free web application. Upload `index.html` to a GitHub repository and deploy using Cloudflare Pages (framework preset: None, build command: blank, output directory: `/`), or use Cloudflare Pages direct upload.

Features: cash purchase, Financeit promotional APR with remaining balance and refinancing choices, mortgage alternative, 20-year cumulative cash flow chart, pricing uplift and selling fees, CSV export. No API keys, backend, or customer data storage.

Important: Financeit contract details must be verified. Monthly loan payment and APR are independent editable assumptions. 14% post-promo rate does not imply a known contractual payment reset. Model assumes monthly nominal APR, fixed promotional payments, and tax financed. Figures are educational, not quotes or financial advice.
