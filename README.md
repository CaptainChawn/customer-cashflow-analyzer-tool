# Riverside Solar Cash Flow Analyzer v6

Standalone HTML for Cloudflare Pages. Replace index.html in your GitHub repository.

## New in v6
- A fairer three-way comparison: cash, Financeit then home equity, and mortgage from day one.
- All scenarios begin with the same investable starting capital equal to the installed price.
- Electricity savings, rebates and payments are added to or deducted from the investment account monthly.
- Outstanding loan balances are deducted from the net financial position.
- Separate charts for net advantage vs investing without solar, investment-account balance, and remaining debt.
- Editable after-tax reinvestment return, default 4.8%.

## Limitations
- Assumes that all cash inflows and outflows can be reinvested/withdrawn at the same constant after-tax return. Negative account balances require other funding, which may have different costs.
- No residual solar asset value, maintenance, inverter/battery replacement, lender fees or refinancing approval.
- The legacy investment comparison tab uses a different simplified capital-gains method; the new strategy chart uses the separate after-tax return field.
- Verify actual financing disclosures, BC Hydro eligibility and customer production before presenting.
